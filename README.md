# New York in Flight

1936 Manhattan’ında bir dartın yolculuğunu takip eden sinematik bir web deneyimi. Kaydırarak atıştan hedefe kadar altı sahneyi ilerlet, zaman çizelgesinden bir sahne seç veya **Oynat** ile yolculuğu baştan sona izle.

## Çalıştırma

Depo kökünde `python3 -m http.server 8080` komutunu çalıştır ve tarayıcıda `http://localhost:8080/` adresini aç. Uygulama düz HTML, CSS ve JavaScript kullanır. Kurulum ya da derleme adımı gerekmez.

## GitHub Pages

Depo ayarlarında **Settings → Pages → Deploy from a branch** yolunu izle. Kaynak olarak **main** ve **/(root)** seç. Tüm sahneler ve yazı tipleri depo içinde tutulur.

## Görseller

`assets/scenes/` dizinindeki altı özgün görsel, 1930’lar Manhattan’ını canlandırmak için üretildi. Kamera, dart, balon ve isabet efektleri tarayıcıda çizilir. Yazı tipi lisansları `assets/fonts/` dizininde yer alır.
